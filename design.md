# FrameForge Design System

## Theme: White Professional

Inspired by img.ly CESDK, clean & modern video editor aesthetic.

## Colors
- Background: #FFFFFF / #F8F9FA / #F2F4F7
- Surface: #FFFFFF
- Surface elevated: #FFFFFF with border #E5E7EB
- Border: #E5E7EB / #D1D5DB
- Text primary: #111827
- Text secondary: #6B7280
- Text muted: #9CA3AF
- Accent: #6366F1 (indigo) - primary actions
- Accent hover: #4F46E5
- Accent light: #EEF2FF
- Success: #10B981
- Warning: #F59E0B
- Danger: #EF4444
- Timeline video track: #818CF8
- Timeline audio track: #34D399
- Timeline text track: #FBBF24
- Timeline effects track: #F472B6

## Typography
- Font: Inter (system-ui fallback)
- Display: 700 weight
- UI: 400/500 weight
- Mono: JetBrains Mono for timecode

## Spacing
- Panel width: 240px (sidebar), 280px (properties)
- Timeline height: 220px min
- Navbar height: 52px
- Track height: 48px

## Style
- Clean flat design with subtle shadows
- 4px border radius for clips
- 8px border radius for panels
- Hairline borders (1px) for separation
- Subtle hover states (bg-gray-50)
- Active states with indigo accent
- No heavy shadows, light elevation only
